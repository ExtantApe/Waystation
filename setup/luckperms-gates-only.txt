# Paste into the server console, line by line. It takes /mvtp away from everyone but admins, while
# waygates keep working. The console keeps it too, as the emergency route.
# To undo it: lp group default parent remove gates-only
#
# The world names below are examples. List your own: one line per world, nether and End included, in
# both the gates-only and admin-mvtp blocks. Group names (family, kids, admin-family) are examples too.
#
# Why each part is here:
# - weight 100 puts this group ahead of family, kids and the rest, which all sit at weight 0.
# - a., e. and pl. are what the pure-creative group grants in creative worlds. Left alone, /mvtp e:
#   would still cross worlds from there. Vanilla /tp is a different permission and isn't touched.
# - every world gets an exact false, since an exact true on family, kids etc. would beat a wildcard.
# - multiverse.access.* stays as it is: gates need it. So do nether portals and TARDIS.
lp creategroup gates-only
lp group gates-only setweight 100
lp group gates-only permission set multiverse.teleport.self.w false
lp group gates-only permission set multiverse.teleport.self.w.* false
lp group gates-only permission set multiverse.teleport.self.a false
